# Square-to-DYMO

Chrome Manifest V3 extension that prints Square Dashboard barcode label PDFs directly to a DYMO LabelWriter 550 over WebUSB, bypassing the ChromeOS print system.

**Status:** Milestone 1 (research). Not yet usable.

## Prerequisites

- Google Chrome (ChromeOS target; developed on macOS)
- DYMO LabelWriter 550 with DYMO 30336 labels (1" × 2⅛")
